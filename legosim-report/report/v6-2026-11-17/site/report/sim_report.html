LegoSim: a first-person LEGO building simulator — technical report

An engine that executes building actions on LEGO models (connector and geometric rules, preconditions, refusal codes), a planner that turns LDraw models and reviewed instruction recipes into action lists, a mistake generator, and a renderer that turns each executed action into first-person rendered video of a person building, with per-frame labels and controllable scenes.

3. How it works

Current API workflow and construction controls

Both Python callers and JSON episodes use Sim. Requests produce an action journal, engine feedback and task progress. Offline motion generation adds trajectories and intended hand contacts; fitting produces evaluated hand poses; rendering writes the head-camera images and labels. The shared exporter derives timed dialogue and causal training samples from that run.

Canonical goal coordinates are separate from committed assembly and subassembly transforms. Construction recipes can interleave any number of distinct copies and nested modules. Built and installed progress are separate; changing a rigid pose does not erase an incorrect connection or misplaced part. Stable placement, connector access and hand ownership can each refuse an action. Support-checked construction and settling have narrower guarantees than a general force simulation; legacy canonical state and authored loose-part put-down retain their documented scopes.

        the chosen hand's side and above the transformed mesh bounds. Clearance

        implied. A successful retry is a separate pick action.

        if (d.shape != (3,) or not np.isfinite(d).all() or abs(d[1]) > 1e-9 or np.linalg.norm(d) < 1e-9
                or type(distance_ldu) not in (int, float) or not np.isfinite(distance_ldu) or not 0 < distance_ldu <= 500
                or hand not in ('L', 'R')):
            raise ValueError('sweep_part needs horizontal direction, L/R hand, and 0 < distance_ldu <= 500')
        tag = f'sweep_part {pid}'
        if pid not in self.parts or self.parts[pid].where != 'table':
            return self._done(Result(False, tag, 'Sweep target is not a loose table part', code='NOT_FREE'))
        if self.hands[hand] is not None:
            return self._done(Result(False, tag, f'Sweep hand {hand} must be free', code='HANDS_BUSY'))
        other = 'L' if hand == 'R' else 'R'
        token = self.hands[other]
        preserved = None
        if token is not None:
            if isinstance(token, str) and token.startswith('model:'):
                root = token[6:]
                held = getattr(self, '_held_model_pose', None)
                if not held or held.get('hand') != other or held.get('pid') != root:
                    return self._done(Result(False, tag,
                        'Sweep beside a held model requires hold_model(..., M=...) with committed world poses',
                        code='EXPLICIT_MODEL_POSE_REQUIRED'))
                preserved = {'hand': other, 'role': 'held_model', 'root': root,
                             'parts': sorted(self.assembly_of(root)), 'pose_mode': 'committed_world_pose'}
            elif isinstance(token, str) and token.startswith('brace:'):
                root = token[6:]
                brace = getattr(self, '_table_braces', {}).get(other)
                if not brace or brace.get('pid') != root:
                    return self._done(Result(False, tag, 'Table brace has no committed support state',
                                             code='UNSUPPORTED_BRACE'))
                failure = self._braced_support_failure()
                if failure:
                    return self._done(Result(False, tag, failure, code='UNSUPPORTED_BRACE'))
                preserved = {'hand': other, 'role': 'table_brace', 'root': root,
                             'parts': sorted(self.assembly_of(root)), 'pose_mode': 'committed_world_pose'}
            else:
                return self._done(Result(False, tag,
                    f'Cannot sweep beside {token}: its held world pose is not committed; set it down first',
                    code='UNCOMMITTED_HELD_POSE'))
        if not hasattr(self, '_loose_supports'):
            return self._done(Result(False, tag, 'Sweep requires a settled_pile scene', code='UNSUPPORTED_PILE'))
        supports = {q: s for q, s in self._loose_supports.items()
                    if q in self.parts and self.parts[q].where == 'table'}
        blockers = sorted(q for q, s in supports.items() if pid in s['under'])
        previously_covered = set(host for support in supports.values() for host in support['under'])
        if blockers:
            return self._done(Result(False, tag, 'Clear supported pieces first',
                                     effect={'obstructing_parts': blockers}, code='PILE_BLOCKED'))
        loose = {q: p.name for q, p in self.parts.items() if p.where == 'table'}
        initial = {q: self.parts[q].T.tolist() for q in loose}
        from legosim.scenes.settling import simulate, static_obstacles, sweep_obstructions
        displacement = d/np.linalg.norm(d)*distance_ldu
        try:
            obstacles = static_obstacles(self)
            blocked = sweep_obstructions(self.parts[pid].name, initial[pid], displacement, obstacles)
        except ValueError as error:
            return self._done(Result(False, tag, str(error), code='UNSUPPORTED_PILE'))
        if blocked:
            return self._done(Result(False, tag,
                'Prescribed sweep intersects passive geometry bounds; choose another direction or clear the obstacle',
                effect={'obstructing_parts': blocked, 'check': 'continuous_translation_of_full_mesh_bounds'},
                code='SWEEP_PATH_BLOCKED'))
        binding = fingerprint({'parts': loose, 'initial': initial, 'obstacles': obstacles,
                               'pid': pid, 'displacement': displacement.tolist()})
        recorded = getattr(self, '_recorded_sweeps', {}).get(binding)
        if recorded is None:
            try:
                result = simulate(loose, initial=initial, obstacles=obstacles,
                                  sweep={'pid': pid, 'displacement_ldu': displacement.tolist()})
            except (ValueError, RuntimeError) as error:
                return self._done(Result(False, tag, str(error), code='PILE_UNSETTLED'))
        else:
            result = copy.deepcopy(recorded)
        if result.get('status') != 'stable' or set(result.get('poses', {})) != set(loose):
            raise ValueError('Recorded sweep has no stable complete endpoint')
        for q, T in result['poses'].items():
            self.parts[q].T = np.asarray(T, float)
        self._loose_supports = copy.deepcopy(result['supports'])
        # Also reused by offline motion generation, preserving exact physics
        # samples even on a machine with a different Bullet build.
        self.__dict__.setdefault('_recorded_sweeps', {})[binding] = copy.deepcopy(result)
        revealed = sorted(previously_covered - set(
            host for support in result['supports'].values() for host in support['under']))
        effect = {'hand': hand, 'driven_part': pid,
            'displacement_ldu': displacement.tolist(), 'simulation_binding': binding,
            'simulation': result, 'uncovered_support_candidates': revealed,
            'recognition': 'not_evaluated', 'human_contact': 'not_evaluated'}
        if preserved is not None:
            effect['preserved_support'] = preserved
        return self._done(Result(True, tag, effect=effect))
