LEGOSIM · V13 · TRAINING-DATA PRODUCTION PILOT

Training-Data Production Pilot

A resumable generator of full-hand LEGO manipulation videos with state-aware interventions, matched branches and annotations derived from realized execution.

This edition reports a bounded pilot run through the production pipeline on 57 planned episodes. Every requested outcome is listed, including failures, inapplicable requests and unsupported interventions. Documentation: docs/production.

Reproduce

source env.local.sh
python -m legosim.cli.dataset plan data/production/pilot.json --batch /var/tmp/legosim-production/pilot --dataset out/datasets/pilot
python -m legosim.cli.dataset run /var/tmp/legosim-production/pilot --stages execute
python -m legosim.cli.dataset plan data/production/pilot.json --batch /var/tmp/legosim-production/pilot --dataset out/datasets/pilot --branches
python -m legosim.cli.dataset run /var/tmp/legosim-production/pilot --cores 0-17 --gpu-lanes 3
python -m legosim.cli.dataset export /var/tmp/legosim-production/pilot
python -m legosim.cli.dataset audit out/datasets/pilot
python -m legosim.cli.dataset profile /var/tmp/legosim-production/pilot
python -m tools.production.pilot_report --batch /var/tmp/legosim-production/pilot --dataset out/datasets/pilot

Limitations

See limitations. Strict anatomical contact is not certified, timing dispersions are assumptions, physical assistance by a second person is unsupported, and downstream model baselines were not run.
